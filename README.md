🍹 QuickDrinks Web Application

📌 Project Overview
QuickDrinks is a dynamic and responsive web application that allows users to:

- Create an account and securely log in
- Browse and search for drinks
- View recommended drink pairings
- Experience personalized interactions
- Explore a responsive and animated user interface
This project demonstrates advanced JavaScript logic, API integration, JSON data usage, local storage management, and enhanced CSS features.

🎯 Project Objectives

This application was built to demonstrate:

- Robust programming logic
- Dynamic content rendering using JSON
- Multiple API endpoint usage
- Advanced CSS styling and animations
- Event-driven JavaScript functionality
- Local storage data persistence

🛠 Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, Transitions)
- JavaScript (ES6+)
- LocalStorage
- JSON Data
- Third-Party API (Cocktail API)

🚀 Features
🔐 Account Creation & Authentication

- Users can register
- Prevents duplicate usernames and emails
- Password validation enforced
- Login using username or email
- Personalized greeting displayed when logged in
- Logout functionality available

🍸 Dynamic Drink Display

- Drinks are dynamically rendered from JSON data
- Uses multiple attributes per drink

🌐 API Integration
The application uses multiple API endpoints including:

- Search by name
- Filter by ingredient
- Lookup drink by ID

These endpoints retrieve JSON data which is used to dynamically generate content.
